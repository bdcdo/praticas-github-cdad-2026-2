# O que é um pull request

O Git e o GitHub funcionam como uma pasta de arquivos inteligente na internet.

Imagine que você escreveu um contrato. Se um colega quiser sugerir uma mudança, ele não mexe no seu texto original. O seu parceiro um fork que é uma cópia idêntica para ele trabalhar sem alterar a sua. Quando ele termina de alterar essa cópia, ele te envia um aviso que por exemplo diz: "Mudei a folha 2, dá uma olhada para ver se aprova". Esse aviso com a sugestão de mudança é o Pull Request.

Você abre esse aviso e o sistema te mostra o seu texto e a ideia do seu parceiro lado a lado. Se você não gostar, você recusa e o seu contrato continua igualzinho. Se você gostar, você aceita e o próprio sistema junta a mudança dele ao seu texto principal.

Assim, vocês trabalham juntos sem bagunça, sem precisar mandar e-mails e sem criar vários arquivos. Tudo fica organizado em um único lugar.
